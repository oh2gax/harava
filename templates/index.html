Drop files here or
Drop all your exports at once: Harava stores every hear once per phone, so overlapping exports add only what is new, and each file tells what it brought. Scan folder reads every new file under {{ watch_folder }}, oldest first.
Coverage every import as a bar over time · click one to analyse its time · log Sit KML off
UseFileOwner · phoneTypeRowsResultCoversShared
Result tells what a file brought: new; extends — a newer export of the rolling log (Fieldwatch exports everything still on the phone, so most rows were already stored); overlaps; duplicate — nothing new; sit update — a newer export of the same running sit. Deleting a file keeps the rows that another file also has. Turn a file off to leave it out without deleting it. A log and a Sit export of the same time work together; a KML of the same phone and time as a log is switched off automatically. Shared: your imports are yours; share one with all users or with chosen users, and it appears under Whose data for them. Admins see everyone's data. Re-read reads the kept original file again.
